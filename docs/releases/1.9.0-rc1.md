# RISC-V Studio 1.9.0-rc1 — Linux

Pré-lançamento para **Ubuntu 26.04 x86-64, com glibc 2.43 ou posterior**.
O pacote para Windows está disponível na versão estável 1.0.0.

## Downloads

- **Instalador DEB:** `RISC-V-Studio-1.9.0-rc1-Linux-amd64.deb`.
- **Portátil:** `RISC-V-Studio-1.9.0-rc1-Linux-x86_64-portable.tar.gz`.
- **Integridade:** `SHA256SUMS.txt`, para os arquivos desta release.
- **Fontes das dependências:** `RISC-V-Studio-1.9.0-rc1-Third-Party-Sources.tar.gz`.
  Não são necessários para instalar ou executar o programa.

Qt, Python, compiladores RISC-V, depurador, bibliotecas de destino, exemplos
e ajuda offline acompanham os pacotes. A exportação para um executável C
nativo requer um compilador do sistema e Make.

## Novidades em relação à 1.0.0

- Ambiente avançado RV32/RV64 com catálogo de extensões, privilégios,
  memória virtual e dispositivos virtuais. Os limites dependem do perfil
  selecionado; consulte o guia de limites do modelo.
- Compilação C17 com GCC 16.2, GNU Assembly, Clang 21.1.8, clangd e GDB 17.1.
- Terminal interativo para `printf`, `puts`, `scanf` e entradas de programas.
- Arquivos virtuais, threads, armazenamento local de thread e as 68
  interfaces opcionais do Anexo K nos SDKs derivados.
- Depuração, inspeção de registradores e memória, histórico reversível e
  projetos salvos, além do ambiente clássico de aprendizado.
- Painéis desacopláveis, controles discretos, visibilidade pelo menu
  Exibir/View e restauração da configuração padrão.
- Tutoriais, exemplos e ajuda com código legível. O editor usa recuo de
  quatro espaços e mantém o alinhamento ao alterar fonte ou zoom.
- Correções de empacotamento, depurador e projetos em caminhos com espaços,
  acentos, `$` e `%`.

## Instalação

Para o DEB, use o instalador de pacotes do Ubuntu ou, na pasta do download:

```sh
sudo apt install ./RISC-V-Studio-1.9.0-rc1-Linux-amd64.deb
```

O executável instalado é `/opt/riscv32-studio/RISC-V-Studio`.
Para o portátil, extraia a pasta inteira e execute `RISC-V-Studio` dentro
dela. `install-desktop.sh` cria um atalho no menu de aplicativos;
`uninstall-desktop.sh` remove esse registro. Registre novamente após mover
a pasta. Salve seus projetos fora da pasta do aplicativo.

Confira o hash do pacote com `sha256sum` e compare a entrada correspondente
em `SHA256SUMS.txt`. Depois de extrair o portátil, também é possível conferir
todos os arquivos, a partir da pasta extraída:

```sh
python/bin/python3 tools/verify_portable.py .
```

## Primeiro uso

Abra um tutorial C de entrada e saída, compile e execute. O painel
**Terminal** mostra as mensagens e permite digitar valores para `scanf`.
Há também Hello World em Assembly. Use **Exibir/View** para reabrir painéis,
desacoplá-los e restaurar o layout. Confira a versão em **Sobre/About**.
